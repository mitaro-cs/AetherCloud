Run a private cloud from your own disk.

AetherCloud is a self-hosted Flask app with a polished storage UI, installable PWA shell, Docker deployment and a workflow centered on your own Windows drive or attached disk.

Quick Start Self-Host Model

MIT licensed. GitHub Actions can test the app and publish this page automatically.

What You Get

Storage, installability and clean self-hosting in one repo.

Bring your own disk Place the database and file blobs on a local volume, mounted SSD or Windows drive letter.
Installable PWA Open the web UI on iOS, Android, Windows and macOS, then install it like an app.
Folder-first dashboard Nested folders, previews, storage meter, recent uploads, profile settings and admin overview.
Self-Host Model

Point the app at your own storage path and expose it only how you want.

1. Choose the storage path Use E:\AetherCloudData, a mounted volume or any server path you trust.
2. Launch the service Use Python for local development or Docker Compose for a cleaner portable deployment.
3. Open from any device Put it behind HTTPS, then install the app shell from Safari, Chrome or Edge.
Quick Start

Run locally or with Docker.

Python 
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export AETHER_STORAGE_DIR="/Volumes/AetherDrive/storage"
python AetherCloud.py
Docker Compose 
cp .env.example .env
docker compose up -d

# Default volume
./data:/data

# Windows disk example
E:/AetherCloudData:/data
