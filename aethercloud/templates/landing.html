Product Direction

Designed for personal nodes, families and small private teams.

Bring Your Own Disk

Keep the binary storage on a Windows drive, external SSD or any mounted volume you trust.

Installable PWA

The web client can be installed like an app on iPhone, Android, Windows and macOS.

Folder-First Workspace

Nested folders, previews, storage meter, recent uploads and personal account settings are ready.

Simple Self-Hosting

Launch with plain Python or Docker Compose, then expose it through a tunnel or reverse proxy.

Self-Host Model

Point the app at your own drive and keep the storage logic local.

01

Choose the storage volume

Use a repo-local folder, a mounted NAS path or a Windows disk like E:\AetherCloudData.

02

Run the service

Start with Python for local testing or Docker Compose for a more portable deployment story.

03

Open it on any device

Add a tunnel or HTTPS reverse proxy, then install the app shell from Safari, Chrome or Edge.

Quick Start

Launch locally in minutes.

Python
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export AETHER_STORAGE_DIR="/Volumes/AetherDrive/storage"
python AetherCloud.py
Docker Compose
cp .env.example .env
docker compose up -d
